# Liquid Glass · UI Layouts

Registro descargado: https://www.ui-layouts.com/r/liquid-glass.json

Repositorio: https://github.com/ui-layouts/uilayouts

Se conserva la adaptación tipada y accesible del mismo componente ya utilizada en Boletera: identificadores SVG únicos, contenido sobre las capas, expansión por teclado y respeto a movimiento reducido. Usa `framer-motion`, ya instalado, en lugar del paquete equivalente `motion/react`. Licencia MIT conservada en LICENSE.

El código está aislado en el playground. El acabado Cristal de la aplicación usa tokens CSS propios sin depender de este bloque ni distorsionar datos.
