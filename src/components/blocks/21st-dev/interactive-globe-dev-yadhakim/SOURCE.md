# Interactive Globe — dev.yadhakim

Origen: https://21st.dev/r/dev.yadhakim/interactive-globe
Autor: dev.yadhakim. Demo 10073 de 21st.dev.

Recuperado mediante el conector de 21st.dev. Canvas 2D sin nuevas dependencias. Conserva puntos, arcos, ciudades, colores y contenido de muestra del autor.
Adaptaciones: tamaño responsive, densidad de píxeles limitada y redimensionamiento solo cuando cambia, callback de dibujo nombrado, import no usado eliminado, movimiento reducido, limpieza de arrastre al cancelar, touch-action y nombre accesible. Se evita división por cero para conexiones antípodas.
Ciudades, conexiones e indicadores son ilustrativos; no consulta infraestructura ni datos del producto.
