# Globe Analytics

Autor: shuding.
Registro: https://21st.dev/r/shuding/cobe-globe-analytics
Recuperado mediante 21st MCP, demo 11605.

Componente COBE original aislado en playground. Visitantes y tendencias simulados localmente, sin analítica real. Import y altura de demo adaptados; ResizeObserver con limpieza y ajuste al redimensionar; giro automático desactivado con movimiento reducido. Etiquetas mediante CSS Anchor Positioning.
