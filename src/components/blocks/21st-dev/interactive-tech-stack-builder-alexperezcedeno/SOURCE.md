# Interactive Tech Stack Builder — alexperezcedeno

Origen: https://21st.dev/r/alexperezcedeno/interactive-tech-stack-builder
Autor: alexperezcedeno. Demo 17874 de 21st.dev.

Código recuperado mediante el conector de 21st.dev. Conserva bloques, SVG, disposición y animaciones originales. Usa framer-motion ya instalado.
Adaptaciones: selección memorizada, limpieza de temporizadores al desmontar, movimiento reducido para vuelo/impacto y MotionConfig, altura adaptable. Wrapper local con confirmación visible y reinicio, en lugar de alertas y logs del demo original. Datos de muestra, sin persistencia ni servicios externos.
