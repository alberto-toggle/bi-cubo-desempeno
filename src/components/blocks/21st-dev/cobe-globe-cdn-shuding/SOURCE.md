# Globe CDN

Autor: shuding.
Registro: https://21st.dev/r/shuding/cobe-globe-cdn
Recuperado mediante 21st MCP, demo 11607.

Demo aislada en el playground; dimensiones adaptadas al contenedor. Tráfico simulado por el componente, sin consultas a una CDN real. Usa COBE, WebGL y CSS Anchor Positioning para marcadores y etiquetas.

Adaptaciones: ResizeObserver para redimensionar y liberar recursos al desmontar, keyframes aislados y giro automático desactivado con movimiento reducido.
