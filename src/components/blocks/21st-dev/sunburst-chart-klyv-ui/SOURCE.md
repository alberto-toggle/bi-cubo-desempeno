# Sunburst Chart — klyv-ui

Origen: https://21st.dev/r/klyv-ui/sunburst-chart
Autor: klyv-ui, publicado en 21st.dev. Demo 38726.

Código del componente y demo recuperados con el conector autenticado de 21st.dev.
Se conserva el trazado SVG, zoom, breadcrumbs, navegación por teclado y datos de muestra originales.

El registro omite los archivos sunburst-chart-utils. utils.tsx contiene equivalentes locales para formato, colores, tooltip, anuncio accesible y animación de entrada; no son código original del autor. Los colores y superficies se adaptaron a tokens semánticos de la plataforma. La demo usa datos ficticios de gastos en nube y está aislada del producto.
