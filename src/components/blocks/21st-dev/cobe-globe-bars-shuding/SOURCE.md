# Globe Bars — shuding

Origen: https://21st.dev/r/shuding/cobe-globe-bars
Autor: shuding, 21st.dev. Demo 11604.

Código y demo recuperados con el conector de 21st.dev. Se utiliza la dependencia cobe ya instalada.
Se conserva el aspecto original y sus porcentajes ficticios por ciudad.
Adaptaciones: import local, altura de preview, ResizeObserver con limpieza y actualización de tamaño, eliminación de timeout de montaje y directiva TypeScript obsoleta, nombre de animación aislado, etiqueta accesible y respeto a movimiento reducido.
Requiere WebGL y CSS Anchor Positioning para las etiquetas. Aislado del producto en el playground.
