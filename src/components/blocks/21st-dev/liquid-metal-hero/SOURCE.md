# Liquid Metal Hero
Autor: chowlol202.
Origen: https://21st.dev/r/chowlol202/liquid-metal-hero
Comando solicitado: `npx @21st-dev/cli add chowlol202/liquid-metal-hero`.
Código y primitivas obtenidos del catálogo autenticado de 21st (demo 5808).

Se preservan contenido, animaciones y callbacks ilustrativos originales.
Primitivas Button, Badge y Card del registro aisladas por proveedor en
src/components/vendors/chowlol202; no reemplazan las primitivas Base UI.
Adaptaciones: shader absoluto y aislado dentro del hero en lugar de fixed global,
altura de sección con espacio para contenido móvil, y uso de preset.params
según la API instalada de Paper Shaders.
Dependencias reutilizadas: Paper Shaders, Framer Motion, Radix Slot y CVA.


En gtyg-platform se recuperó nuevamente el original autenticado (demo 5808), conservado en original.tsx.txt. Se reutiliza la adaptación ya validada en toggle-landing. La alternativa del login utiliza Paper Shaders directamente, sin importar este bloque ni sus primitivas.
